# Daily drills

One folder per day: `drills/YYYY-MM-DD/`.

Copy `_template/` when a session starts.

- `00-brief.md` — the 3 concepts and the code prompts (agent writes this).
- `01-*.swift`, `02-*.swift`, `03-*.swift` — your answers.
- `from-code.md` — optional questions generated from that day’s other Swift diffs. Star from here into `tracker/super-important/`.

Status for the matching rows in `tracker/topics.json` is updated after review: `in_progress` → `drilled` or `starred`.
