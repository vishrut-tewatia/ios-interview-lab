# Tracker

Source of truth for what is covered.

| Path | Role |
| --- | --- |
| `topics.json` | Vast living curriculum (Swift, UIKit, concurrency, design, DSA, …). Status: `not_started` \| `in_progress` \| `drilled` \| `starred`. Daily 3 follows `pick_order`. Add a row when a real question has no home. |
| `super-important/` | Short list you re-answer. Theory + generic Swift. |
| `_card-template.md` | Shape of a starred card |

A topic is **ticked** when status is `drilled` or `starred`. Star only what has shown up in real company loops or that you keep missing.

Do not keep a parallel list in Notion or in chat.
